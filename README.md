# Романтический опросник для Кати 💗

Статический сайт на HTML, CSS и JavaScript. Сервер и сборка не нужны.

## Перед публикацией
1. Положи первую фотографию в эту папку и назови `photo1.jpg`.
2. Положи вторую фотографию и назови `photo2.jpg`.
3. Если изображения в другом формате, поменяй расширение в `index.html` (например, `photo1.png`).

## Публикация на GitHub Pages
1. Войди в GitHub под аккаунтом `KnyazevV160`.
2. Создай **публичный** репозиторий с точным названием `KnyazevV160.github.io`.
3. Загрузи в корень репозитория файлы `index.html`, `style.css`, `script.js`, `photo1.jpg`, `photo2.jpg`.
4. Открой **Settings → Pages**.
5. В разделе Build and deployment выбери **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажми **Save**.
6. Подожди несколько минут. Сайт будет доступен по адресу:
   https://knyazevv160.github.io/

## Важно
- Если хочешь сохранить фотографии личными, не публикуй их на общедоступном сайте. Файлы в публичном репозитории и изображения на опубликованном сайте смогут просматривать другие люди.
- Ответы нигде не собираются и не отправляются: это интерактивная романтическая страничка, а не форма с базой данных.
